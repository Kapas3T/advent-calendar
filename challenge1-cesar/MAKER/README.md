## Infos générales :
Le **thème** de ce challenge est : **La cryptogtaphie**
Vous trouvez le *flag* sous **cette forme** : `great super secret flag`
C'est une **phrase** complètement **lisible** en **englais**
Vous êtes priés de **rajouter** `EN{}` et de **séparer le mots** par des **underscores** `_`.
Vous finirez avec un format similaire à celui-ci : `EN{great_super_secret_flag}`.

Si vous êtes bloqués ou que vous avez besoin d'un indice, décompressez `HINT.zip` avec le mot de passe `H1NT_23`.
N'ouvrez que le `hint_etape` de l'étape ou vous êtes bloqués ou celles précédentes.
